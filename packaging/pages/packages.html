LyricsLens

The line being sung, over every window — including one in fullscreen. It reads what your player is playing, finds the words, and keeps them in time. Linux, no account, no tracking.

Install

Into ~/.local, no root, nothing outside your home directory.

curl -fsSL https://raw.githubusercontent.com/byjuliocesa/lyricslens/main/install.sh | sh

Then run lyricslens, or lls. It puts an icon in the status bar and stays out of the way.

Packages

.deb (${VERSION}) .rpm (${VERSION}) every release

Install a package with apt install ./file.deb rather than dpkg -i: only the first pulls in what it needs.

What it needs

glibc2.39 or newer
GTK4.12 or newer
libadwaita1.5 or newer

Which means Ubuntu 24.04, Debian 13, Fedora 40, openSUSE Tumbleweed or Arch, and anything newer. The layer-shell library is built into the binary, so there is nothing to install for it.

A player that reports where it is in the track. Spotify, mpv with mpv-mpris, Rhythmbox and Amberol do. Firefox does not for some of what it plays, and the overlay says so rather than guessing.

Updates, from your package manager

These repositories carry the same binary the archive does. A machine that installs from them gets new versions with the rest of its updates.

Debian, Ubuntu, Mint

curl -fsSL https://byjuliocesa.github.io/lyricslens/lyricslens.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/lyricslens.gpg

echo "deb [signed-by=/usr/share/keyrings/lyricslens.gpg] https://byjuliocesa.github.io/lyricslens/apt ./" \
  | sudo tee /etc/apt/sources.list.d/lyricslens.list

sudo apt update && sudo apt install lyricslens

Fedora, openSUSE

sudo rpm --import https://byjuliocesa.github.io/lyricslens/lyricslens.asc

sudo tee /etc/yum.repos.d/lyricslens.repo <<'REPO'
[lyricslens]
name=LyricsLens
baseurl=https://byjuliocesa.github.io/lyricslens/rpm
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://byjuliocesa.github.io/lyricslens/lyricslens.asc
REPO

sudo dnf install lyricslens

The key

Everything here is signed with this one. Check it against what your machine imported before trusting either.

${FINGERPRINT}

Removing it

lyricslens --uninstall

sudo rm /etc/apt/sources.list.d/lyricslens.list /usr/share/keyrings/lyricslens.gpg
sudo rm /etc/yum.repos.d/lyricslens.repo
